# QBC 資料ライブラリ

クイックビューティークリニックの会議資料・HTMLガイドをまとめる場所です。

- 閲覧用ページ：<https://kojikagino.github.io/qbc-materials/>
- 元のNotion資料ライブラリも、そのまま利用できます。
- 資料と元ファイルは一般公開です。追加・差し替えは、招待されたGitHubアカウントだけが行えます。

## HTML資料を追加する

1. 招待されたGitHubアカウントでログインします。
2. このリポジトリの **Add file → Upload files** を開きます。閲覧用ページの「資料を追加する」からも進めます。
3. 完成したHTMLファイルをアップロードします。
4. **Commit changes** を押して保存します。
5. 公開処理が終わると、資料一覧に自動で表示されます。反映には数分かかることがあります。

ファイル名が資料一覧の表示名になります。内容が分かる日本語の名前（例：`2026年12月 経営会議.html`）で保存してください。各資料の画像やCSSは、HTML内に同梱した形式にすると扱いやすくなります。

## 同じ資料を差し替える

同じ名前・同じ場所のHTMLファイルを **Add file → Upload files** からアップロードし、**Commit changes** で保存します。資料のURLは変わらず、変更履歴も残ります。

`index.html` は資料一覧のページです。個別資料のファイル名には使わないでください。

## 公開・編集権限

閲覧する人はGitHubの操作をする必要がなく、共有された閲覧用URLを開くだけで読めます。追加・差し替えを担当する人は、リポジトリの招待を受けてからGitHubへログインします。

このリポジトリへ置いたファイルは、HTML以外も含めて誰でも取得できます。一般公開しない資料は、ここへアップロードしないでください。

## 管理者向け

GitHub Pagesの公開元を **Deploy from a branch → main → /(root)** に設定します。JekyllがHTMLファイルの一覧を毎回生成するため、`.nojekyll` は追加しないでください。

- `index.html`：資料一覧。HTMLファイルを自動列挙します。
- `_config.yml`：公開先とサイト名の設定。
- 個別の`.html`ファイル：元のデザインのまま配信する資料。

最初の資料「痩身領域の薬 マーケ向けガイド」は、元のHTMLを内容・デザインとも変更せず格納しています。
